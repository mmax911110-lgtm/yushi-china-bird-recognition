# 分类头与底层骨干优化实验分支

本分支从原仓库 main 的 efdd37fff80c10ed262b9bc7bb1f365eef46219f 建立，归档此前已完成的研究。未开展新训练，也未替换 NVIDIA 成品目录中的代码或权重。原 main 的文件保持不变。

当前保留的部署方案是第四版 YOLO11n 检测、背景复核、逐框裁图，以及 BioCLIP2 适配头与 BioCLIP2.5 Ridge 头的 50:50 校准概率融合（blend50_N_ridge）。骨干名字相同不代表没有修改分类头。deployment_reference 保存这一实际部署的小型代码与配置快照用于对照，不含权重。

## 已做过什么，效果如何

| 实验 | 比较口径 | 结果 |
|---|---|---|
| BioCLIP2 新监督分类头 | 61图、80类范围，原单路头 vs 新头 | 56/61 → 57/61；多对1张 |
| 当前部署 BioCLIP2 + BioCLIP2.5 | 同一61图、80类范围 | 57/61；新单路头没有超过当前双路 |
| 冻结 BioCLIP2 + DINOv2-S/14 投影/拼接/MLP | 同一61图、80类范围 | 57/61；没有部署升级收益，未继续局部 Patch |
| 真实骨干末块微调 | 18组训练：12微调 + 6冻结对照 | 验证未过升级门槛，deployment_candidate=None |
| 预先冻结的研究候选 vs 当前双路 | 后续95张观察记录级测试 | 79/95 vs 80/95，0纠正/1误改 |

上表是当时保存的图片/主框级研究口径，不是“图中所有鸟”的逐鸟准确率，也不能外推到1,343种全部鸟种。61图与95图均已评分，后续选参需要另用开发数据，并准备新的最终测试集。

## 文件

- bioclip_dinov2_audit_20261113：项目审查代码、报告、类别范围和原部署保护摘要。
- dinov2_species_20261113：独立编码器、投影/MLP分类头、训练/评估/推理与烟雾测试；保留固定版本的 DINOv2 官方源码、LICENSE 和权重来源摘要。
- finetune_species_20261113：DINOv2 与 BioCLIP2 视觉末层微调、冻结对照、新测试收集/评分与错误分析代码，配置及已完成训练的小型记录。
- deployment_reference：现有 NVIDIA 部署源码与配置的只读对照快照。
- snapshot_manifest.json：上述原文件的逐项 SHA256 与大小，明确是归档、不是重新训练产物。

原研究代码和报告按字节保留，旧报告中的绝对文件链接仍指向原机目录。训练权重、数据图片、特征数组和逐图测试数据未加入 Git；本分支不是完整离线运行包。原入口使用本机 NVIDIA/runtime/python.exe、NVIDIA/app 和原归档数据。要在原机继续研究，应对照原目录使用这些代码及本地资产；克隆到其他机器后需自行准备依赖、数据与模型，不能直接运行就声称复现实验。

第三方 DINOv2 代码遵循其目录内 LICENSE，固定 revision 和权重摘要见 dinov2_species_20261113/assets/dinov2.json。本项目原创代码沿用仓库 USAGE.md；未重新许可第三方组件或数据。
